# Implement Feature

1. Run repository investigation first.
2. Create an implementation plan for non-trivial work.
3. Check `git status` and preserve unrelated changes.
4. Follow existing architecture, naming, dependency and error-handling patterns.
5. Make the smallest complete change that satisfies the acceptance criteria.
6. Add or update tests with the behavior, not afterward as decoration.
7. Avoid new dependencies unless they provide clear value and fit project policy.
8. Do not bypass type, lint, security, authorization or validation controls to make implementation easier.
9. Run FAST verification during the loop.
10. Run FULL verification before declaring the task complete.
11. Review the final diff for scope creep, debug artifacts, secrets and accidental generated files.
12. Summarize changed behavior and provide verification evidence.
