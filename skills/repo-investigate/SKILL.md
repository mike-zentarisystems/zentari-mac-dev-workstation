# Repository Investigation

Before asking the user or changing code, inspect the repository.

1. Read repository instructions, README, AGENTS.md, contribution docs and architecture docs.
2. Inspect manifests, lockfiles, configs, tests, CI and container definitions.
3. Search for the relevant symbols, routes, components, configuration and existing patterns.
4. Identify the actual runtime, package manager, test commands and deployment path.
5. Check `git status` before editing and preserve unrelated user changes.
6. State assumptions only when they cannot be resolved from the repository or available tools.
7. Prefer the smallest change that follows existing project patterns.
